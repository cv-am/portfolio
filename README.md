# Shivam Singh | The Anti-Gravity Sketchbook Portfolio 📓✏️

A handcrafted, paper-styled developer portfolio built for **Shivam Singh** (`@cv-am`) featuring real GitHub project showcases, an interactive doodle canvas drawer, an executable notebook terminal, Web Audio pencil sounds, and zero-gravity floating physics.

---

## 🚀 Quick Start (Run Locally in 2 Minutes)

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18 or higher recommended) installed.

### Steps:
1. **Unzip the folder** and navigate inside the project directory:
   ```bash
   cd shivam-sketchbook-portfolio
   ```

2. **Install the dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. Open `http://localhost:3000` (or the URL Vite provides) in your browser!

---

## 📦 Build for Production / GitHub Pages / Vercel

To create an optimized production build for deployment:
```bash
npm run build
```
This will generate a lightning-fast static bundle inside the `dist/` directory ready to drag-and-drop onto Vercel, Netlify, or deploy to GitHub Pages.

## 🛠️ Tech Stack Included
- **Vite** — Blazing fast frontend build tool
- **React 18** — Component architecture
- **Tailwind CSS 3** — Utility-first styling with custom hand-drawn utilities
- **Lucide React** — Minimalist vector icons
- **Web Audio API** — Real-time synthesized pencil scribbles and rubber stamp acoustics (no external audio files needed)
- **Google Fonts** — *Architects Daughter*, *Caveat*, *Patrick Hand*, *Space Mono*

---

## 🎨 Interactive Features Included
- **Zero-Gravity Mode:** Tap the Anti-Gravity button to trigger floating CSS matrix physics.
- **Doodle Pad:** Click the pen icon to draw directly on the sketchbook canvas with selectable colors and stroke widths.
- **Sketched Terminal:** Interactive terminal with commands: `help`, `skills`, `projects`, `antigravity`, `whoami`, `contact`.
- **4 Paper Themes:** Notebook Grid, Blueprint Blue, Vintage Parchment, and Chalkboard.
- **Real GitHub Projects:** Spotlights `cv-am/book-flight`, `cv-am/authentication-project`, and `ragini-saxena/Investor_fund_collection`.
