# 📓 Shivam Singh | Anti-Gravity Sketchbook Portfolio

A creative, interactive developer portfolio inspired by the charm of a handwritten sketchbook. Built with React, Tailwind CSS, and Vite, it combines a paper-inspired visual identity with playful interactions to showcase my projects, technical skills, and developer journey.

**[🌐 Live Portfolio](https://cv-am.github.io/portfolio/) · [💻 GitHub Repository](https://github.com/cv-am/portfolio)**

---

## ✨ Overview

Why settle for an ordinary portfolio when your work can feel like opening a developer's notebook?

The Anti-Gravity Sketchbook Portfolio brings together hand-drawn aesthetics, interactive elements, and real project showcases in one experience. From an executable notebook terminal to a zero-gravity mode, every feature adds a little personality to the way I present my work.

## 🚀 Features

- **📓 Sketchbook-Inspired UI** — A paper-like interface with handwritten typography and custom sketch-style elements.
- **🪐 Anti-Gravity Mode** — Activate a playful floating effect that brings elements to life.
- **✏️ Interactive Doodle Pad** — Draw directly on the canvas with selectable colors and stroke widths.
- **💻 Executable Notebook Terminal** — Explore the portfolio using commands such as `help`, `skills`, `projects`, `whoami`, and `contact`.
- **🎨 Four Paper Themes** — Switch between Notebook Grid, Blueprint Blue, Vintage Parchment, and Chalkboard.
- **🔊 Procedural Pencil Sounds** — Web Audio API-generated sound effects without external audio files.
- **🗂️ Real Project Showcases** — Explore selected projects through GitHub links.
- **📱 Responsive Experience** — Designed to make the portfolio accessible across different screen sizes.

## ⚙️ Getting Started

Want to run the project locally? Follow these steps.

### Prerequisites

- [Node.js](https://nodejs.org/) — Version 18 or higher recommended.
- npm — Included with Node.js.
- Git — Recommended for cloning the repository.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/cv-am/portfolio.git
```

**2. Navigate to the project directory**

```bash
cd portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL**

Open the URL printed in your terminal by Vite, usually:

```text
http://localhost:5173
```

You're ready to explore and modify the portfolio!

## 📦 Production Build

Create an optimized production build:

```bash
npm run build
```

Vite generates the production files in the `dist/` directory.

To preview the production build locally:

```bash
npm run preview
```
